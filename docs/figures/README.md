- `deployment-example.png`: generated with `demo_deployment` in this cleanup.
- `inverse-example.png`: generated with `demo_inverse_design('rigid')` in this cleanup. See `../validation.md` for diagnostics.

Original paper figures explain the research; new example figures illustrate the maintained code. They should not be confused with exact reproduction of a published figure.
